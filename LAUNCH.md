# Launch clock

Starts at the first public post. Pre-registered 2026-09-02, before the
clock started; dates filled the day the post goes up.

- Start date: TBD (first public post)
- Check date: start date + 14 days

GO needs any one of:

- [ ] 25 or more GitHub stars
- [ ] A cite or share from an account with a real incident-response
  audience, in their own words (a repost without comment does not
  count)
- [ ] An issue or message from a practitioner who ran it on their own
  artifacts ("I ran this on my own session")

If two of three hit, this is a project. If one hits, the honest move
is to ask that one person what they need next before building
anything. If zero hit, the project parks and that decision is written
here with the date.
